# 💰 Expense Tracker API

A full-stack expense tracker with JWT authentication and REST API.

## Live Demo
🌐 [Try it here](your-render-link)

## Features
- Register & Login with JWT tokens
- Add, edit, delete expenses
- Filter by category
- Spending summary & stats
- Secure — each user only sees their own data

## Tech Stack
Python · Flask · SQLAlchemy · SQLite · JWT · Bcrypt · HTML/CSS/JS

## Run Locally
pip install -r requirements.txt
python app.py
